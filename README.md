# multiverse-bauni

This repository contains a production-oriented end-to-end encrypted realtime messaging reference implementation for The Multiverse Portal.

Contents:
- backend/: Fastify + WebSocket server, Postgres migrations.
- client/: client library using libsignal-protocol-js (bundled) and build scripts.
- examples/: integration snippets and a single-file inline HTML for quick testing.

See README in the repository for setup and run instructions.
